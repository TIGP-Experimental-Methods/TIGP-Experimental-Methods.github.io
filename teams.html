The class project wall

One page with every project in the class, as cards: a picture, a title, the student, a one-line blurb and links to the project website and the repository (the project folder with its full history, kept online on GitHub). The wall refreshes itself every minute, and it is on the projector in class — so everyone sees each other's projects appear, borrows ideas and starts talking.

The wall is the repository TIGP-Experimental-Methods/showcase-2026, published with GitHub Pages; every student can push to it.

How to add yourself

  1. Finish a project: its own public GitHub repository under your account, its project website live (GitHub Pages of that repository, https://<user>.github.io/<repo>/ — title, what it is and why it is interesting, how it works, a picture, GIF or short video of it working, what was verified, links to the live app and to the repository).
  2. At the end of the project the tutor adds your entry — one JSON file and one picture — in the format the README of the wall's repository describes.
  3. You push it. Within a minute your card is on the wall — and on the projector.

One card per project: Project 1 (the web app), Project 2 (the phone app for the ESP32) and Project 3 — your instrument: board section, firmware, housing — one card, one repository and one project website for the whole of Project 3 (the KiCad design files stay in the class repository; your repository presents the work — pictures, renders or video, what it does, what was measured — and links to your pull requests).
