班級專案牆

一個頁面，放著全班每一個專案，以卡片呈現：一張圖片、標題、學生、一行簡介，以及連到專案網站與儲存庫（repository：保存完整歷史的專案資料夾，放在 GitHub 上）的連結。專案牆每分鐘自動更新，上課時投影在螢幕上——所以大家都看得到彼此的專案陸續出現，互相借用點子、開始交談。

專案牆就是儲存庫 TIGP-Experimental-Methods/showcase-2026，以 GitHub Pages 發布；每位學生都能推送（push）到它。

如何加入你的專案

  1. 完成一個專案：你帳號下自己的公開 GitHub 儲存庫，它的專案網站已上線（該儲存庫的 GitHub Pages，網址 https://<user>.github.io/<repo>/——標題、它是什麼、為什麼有趣、如何運作、一張它運作中的照片、GIF 或短片、驗證了什麼、連到線上 App 與儲存庫的連結）。
  2. 專案結束時，家教替你加上條目——一個 JSON 檔加一張圖片——格式依專案牆儲存庫的 README 說明。
  3. 由你推送。一分鐘內你的卡片就會出現在專案牆上——也出現在投影機上。

每個專案一張卡片：專案 1（網頁應用程式）、專案 2（ESP32 的手機 App），以及專案 3——你的儀器：板上區塊、韌體、外殼——整個專案 3 只有一張卡片、一個儲存庫、一個專案網站（KiCad 設計檔留在班級儲存庫；你的儲存庫呈現這件作品——照片、渲染圖或影片、它做什麼、量到了什麼——並連到你的拉取請求）。
