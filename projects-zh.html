班級儀器：函數波形產生器／任意波形產生器（AWG）兼實驗室控制器

每個人都打造同一套儀器平台——一台每個實驗室都用得上的桌上型「瑞士刀」。2026 年度的做法是一塊班級板，分成五個區塊（section），每位學生負責一個——專案 3a（電路板，用 KiCad 設計）與專案 3b（它的外殼）。 硬體刻意標準化，讓工作坊、設計審查與全班統一的印刷電路板（PCB）訂單方向一致； 你發揮的空間在軟體：介面、自動化與細節打磨，讓一塊電路板變成人人愛用的儀器。

這台儀器能做什麼

  • 產生訊號：16 位元雙通道任意波形產生器——直流電位、斜波、正弦波與任意波形表，頻率到約 50 kHz、振幅 ±10 V（AO1、AO2）——再加上兩路硬體定時的觸發／時鐘輸出（5 V TTL），可達數十 MHz。
  • 監測訊號：八路 16 位元 ±10 V 類比輸入，全部走 SMA 接頭（AI1–AI8），量程可由軟體切換、最小到 ±0.64 V 以配合感測器量測，並記錄、繪圖。板上另預留一組儀表放大器／可程式增益的訊號調理鏈，作為授課教師的選配，接到第 7、8 路輸入。
  • 切換開關：四路低電壓繼電器、八路 5 V TTL 輸出、兩路高速光耦隔離輸入，以及一個可由韌體（firmware）切換輸入／輸出方向的 TRIG 接頭——警報、連鎖保護（interlock）、序列動作。
  • 什麼都能連：以原生 USB 連 Python；以 WiFi 連網頁、手機與訊息機器人。你的手機就是前面板（板上一顆小 OLED 顯示狀態）；選配的相機節點可把影像串流進同一個 App——想試做相機 App 的人，有一台 ESP32-S3-N16R8-CAM 開發板 + OV3660 鏡頭（金華 #41395）可用。

MCU——微控制器（microcontroller，單晶片上的小電腦）的選擇（2026 年度已定案）：採用標準 DevKitC-1 腳位、附外接天線接頭的 ESP32-S3 N16R8 開發板（dev board）（金華，NT$400），插在班級板的插座上，執行 Arduino 框架。有 WiFi 就能發展網頁／手機／機器人方向；u.FL 天線接到 SMA 穿板座，讓 WiFi 在密閉的金屬或壓克力外殼內也能用；開發板留下 31 個可用 GPIO（通用腳位）與一條 80 MHz 的 SPI 匯流排（晶片與微控制器對話的常見接線標準）給轉換器使用。核心電路採統一規格，讓全班訂單與設計審查得以順利進行——但你依然要在這塊板子上動手做真正的硬體工作（見下段），你的創意也同時展現在韌體（在微控制器上執行的程式）、主機端軟體、介面與外殼上。

一塊班級板、五個區塊——你負責其中一個。整塊板子是同一個 KiCad（電路設計軟體）專案，放在一個班級儲存庫（repository：由 git 保存完整歷史的共用專案資料夾，放在 GitHub 上）裡。授課教師先把整塊板子做完——基礎部分（開發板插座、匯流排、擴充排針、帶 12 個 SMA 接頭的前面板 PCB）加上全部五個區塊——再交給你完整電路圖（schematic）的 PDF，以及你那個區塊電路圖的「留白」版本（刻意刪掉幾個零件）。五個區塊：精密輸入（ADS8688，AI1–AI8）、電源與電源軌（USB-C／5 V 插座、±12 V 隔離模組、穩壓器）、訊號產生（DAC8563＋±10 V 輸出級）、隔離切換（繼電器＋高速光耦輸入）與數位 I/O 與定時（TTL 輸出、高速觸發輸出、TRIG 接頭）。你的工作——每一步都只做一次，由 Claude 家教（tutor）陪你走：對照 PDF 補回被刪掉的零件、從 LCSC 抓一個零件（LCSC 是 JLCPCB——組裝我們電路板的工廠——的零件目錄）進零件庫、在板上屬於你的區域內佈線（routing：在屬於你的範圍內畫出銅箔走線；IC 與接頭已預先放好）、發出拉取請求（pull request，簡稱 PR：請求把你的修改併入共用專案，會先有人審查）並審查一位同學的，然後依模板寫出你區塊的韌體驅動與 App 面板——先在模擬模式（SIM mode）下完成，板子到貨後再上真實硬體。合併（merge）後的設計在 9月28日（一）下午 2 點（硬性截止）送進全班訂單，製作五份——每人一台組裝完成的儀器。你的區域、你的拉取請求，以及你對同學的審查，就是你在專案 3a 的部分；外殼則是專案 3b。

規則：僅限低電壓——儀器由 USB-C 或 5 V 電源供電，繼電器只切換訊號級與 ≤ 30 V DC 的負載，絕不碰市電。零件須為 JLCPCB 現貨；開發板由課程提供。成本：班級板是同一份設計製作五份，零件依「每一塊錢能學到多少」挑選——每位學生約 NT$3.2k（≈ US$100）全包：開發板、零件、四層 PCB、前面板 PCB 與 JLCPCB 全部組裝，沒有任何需要自己焊接的東西。每個零件都必須物有所值，JLC 報價在下單前檢查。

其他想法：可加在 ESP32 這類開發板上的擴充硬體

本課程的硬體是固定的——同一份電路板設計，全班一次訂購；下面這份清單裡沒有任何一項屬於課程內容，也不是給學生的延伸題。放在這裡純粹作為靈感：把哪些擴充硬體加到 ESP32 這類開發板上，可以做出其他對實驗室有用的工具——課程結束之後，或在你自己的工作裡。班級板保留了一組 2×10 擴充排針、兩個 Qwiic 接頭與幾個預留的封裝（footprint：尚未裝件零件的銅箔圖形），日後仍有可能加上這些東西。以下皆採 JLCPCB 現貨零件。

🏎 高速擷取

ADS9224R 雙通道 16 位元 3 MSPS，或 AD9235 40 MSPS 接在閒置的 LCD_CAM 平行埠上：擷取快速的暫態訊號——2026 年度核心電路為了成本與時程而移除的等級。

〰 DDS 正弦波源

AD9833 直接數位合成，正弦波到 1 MHz，掛在擴充排針的 SPI 上：與 16 位元 AWG 互補，把訊號源的頻率上限往上推。

🧮 精密 ADC

ADS1115／ADS1256：16–24 位真實解析度，適合 µV 級與感測器量測。看見 MCU 內建 ADC 看不見的東西——再用雜訊底限圖證明它。

🔢 更多通道

MCP23017（+16 GPIO）與 CD74HC4067（16 路類比輸入共用一腳）：兩顆便宜晶片掛在同一條匯流排上，通道數就超越 Arduino Mega。

🎚 可程式增益／自動量程

PGA113 或數位電位器設定增益：輸入級會自己切換量程，弱訊號與強訊號都落在刻度內。班級板在第 7、8 路輸入上預留了未上件的 PGA113 封裝——把它裝上、寫好驅動。

⚖️ 儀表放大器輸入級

INA826／INA333 級差動前端：電橋、熱電偶與疊在雜訊接地上的微小訊號，都能乾淨量測。班級板的訊號調理區預留了 INA826 的封裝。

🌡 精密溫度通道

MAX31865 + PT100/PT1000 或熱敏電阻電橋：mK 級測溫——實驗室 PID 的感測端。

🔥 加熱器／TEC 驅動

MOSFET PWM 級加上 INA 電流偵測：致動端——對雷射座或樣品台做閉迴路溫控。

🚶 運動驅動

A4988／DRV8825 步進馬達驅動或伺服機接頭：快門、濾光片輪、斬波器——全都聽你的觸發引擎指揮。

⏰ 真正的時基

TCXO（±1–2 ppm）加上外部 10 MHz 參考輸入：把訊號產生器升級成計量級訊號源——再用兩塊板互拍（beat）量出改善幅度。班級板上有一個未上件的 TCXO 封裝。

🔗 隔離式 RS-485／CAN

橫跨實驗室、電氣隔離的多點儀器匯流排——真實設施就是這樣把設備串起來的。

🖥 觸控螢幕前面板

手機／網頁 App 才是這台儀器的臉，班級板上的小 OLED 顯示狀態；若想要能獨立操作的面板，可在前面板 PCB 上加一片 3.5″ 480×320 TFT（ILI9488，SPI）與電容式觸控（FT6236／GT911，I²C——另一種晶片間匯流排），以 LVGL 驅動。輕量版：OLED＋旋轉編碼器。

💾 記錄 + 時鐘

microSD 插槽 + DS3231 RTC：不需主機也能記錄數週的含時間戳資料——想拿資料時再用 WiFi 取回。

🔋 電池供電

TP4056 充電器 + 升壓轉換器：可攜式現場量測，停電也不中斷記錄。

💡 光電二極體／TIA 輸入

互阻抗（TIA）光量測通道：雷射功率監測、螢光偵測——佈局品質真正見真章的類比設計。班級板的訊號調理區預留了 OPA2156 TIA 的封裝。

⚡ 電源監測

INA226 監看自己的電源軌：儀器自己量測電流、電壓與能耗——內建自我診斷。

🔊 音頻級編解碼器

I²S ADC/DAC：高傳真類比路徑，把數位濾波器與軟體鎖相放大器方向升級到 24 位品質。

🛡 更多開關

加裝繼電器或高側開關，含正確的飛輪二極體與隔離：把警報／連鎖保護的輸出規模擴大到一整個機架。

超越基準線：做出很棒的東西

成果發表與展示（10月26–30日，每人約 15 分鐘）對每個人都有同一套建議的流程（見下）。軟體、韌體、App，以及圍繞這台儀器的一切，都由你決定要推到多遠——挑一個對你自己的實驗室真正有幫助的方向，或單純挑一個你會很自豪拿出來展示的東西：

📱 手機 App／網頁介面

由 ESP32 提供一個精緻的網頁應用程式（可安裝的 PWA：像 App 一樣運作的網頁）：波形控制、即時讀值、深色模式、多使用者。在研討室裡也能操控你的儀器。

🔔 監測、警報與繼電器

對類比輸入設定門檻規則：觸發繼電器、鎖住連鎖保護、推送 Telegram／LINE 警報。故障安全（fail-safe）的預設值、手動重置、含時間戳記的事件記錄。

⏱ 觸發與序列控制

觸發輸入 → 波形爆發（burst）或繼電器動作；可程式化的序列與排程；讓兩台裝置同步。把波形產生器變成實驗的總指揮。

🐍 Python API 與腳本

乾淨俐落的 instrument.sine(1e3, 0.5) API；自動掃描；用你自己的產生器＋ADC 量測濾波器的轉移函數並繪圖。

📈 校正與特性量測

校正振幅與頻率；在示波器上量測頻寬、失真、輸出阻抗；發布一頁規格書風格的規格頁。物理內涵就在這裡。

🌐 多儀器系統

用 MQTT 或 REST 串連多台裝置；用一個儀表板看遍整個實驗室；把同學的儀器當作用戶端。迷你版的系統工程。

🛠 韌體工藝

穩健的狀態機、看門狗（watchdog）、重開機後仍保留的設定、OTA（over-the-air，即經由 WiFi）更新（ESP32）、開機自我測試。這就是展示品與產品的差別。

🎛 前面板與外殼細節

以 PCB 製作前面板，附絲印標示、導光柱、OLED 狀態顯示，以及（選配）與手機 App 共用同一套 API 的觸控介面（LVGL）；一個看起來像買來的、而不是自己拼出來的外殼。

🎬 把成果展現出來

一支介紹這塊板子的影片 · 一頁使用 AI 或 KiCad 的訣竅 · 一個精緻的網頁 · 一個能教會別人某件事的遊戲。把東西好好呈現本身就是一項技能。盡管做出很棒的東西。

你自己實驗室的需求指向不同的想法？很好——寫進你的規格書。電路板本身不會改變。

展示——建議的流程

成果發表與展示在 10月26–30日進行，每人約 15 分鐘。展示部分的建議流程：

  1. 產生指定的波形（頻率＋振幅），並在示波器上展示。
  2. 用你選擇的介面（手機／網頁／Python／機器人）改變輸出。
  3. 對某路類比輸入設定警報門檻；展示繼電器動作與通知。
  4. 展示你負責的區塊：它的 App 面板與它能做的一件事——以及你的專題網站。
  5. 你在基準線之外做的任何東西——資料記錄器、LINE 警報、PID 區塊、Python 掃描、你實驗室需要的工具。

備援方案：韌體的模擬模式能在單獨的開發板上跑出 App 與每個面板——如果板子遲到或故障，就展示這個，完全不丟臉。

影片：歡迎在成果發表中加入一支介紹你的 App 與電路板的影片（例如透過專案 1 的流程：Markdown → 投影片 → 網站 → YouTube）；這是選配，現場展示出狀況時就播放它。

製作計畫（與工作坊同步進行）

專題在工作坊的幾週內同步進行，與你的研究並行——而不是課程結束後的第二份工作。每次工作階段（session）結束都要提交（commit：附一行說明、存下你修改的快照）並留下交接筆記；每一章都由 Claude 家教陪你走完。

成果發表與展示（2026 年 10月26–30日）

約在 10月16日（五）領取製作完成的 PCB 與外殼；組裝你的 ESP32、PCB 與外殼；測試並精修你的韌體與 App。然後在 10月26–30日那一週發表並展示你的專題——每人約 15 分鐘，以英文進行；鼓勵使用 AI 協助準備。

  • 展示——依上方建議的流程：輸出一個波形，在示波器與儀器自己的輸入上看到它 · 用手機改變它 · 某路輸入的警報 → 繼電器 → 通知 · 你負責的區塊：它的面板與它能做的一件事 · 你在基準線之外做的東西。
  • 發表——你做了什麼、為什麼做，哪些成功、你學到什麼；建立在共用硬體之上的軟體，正是你展現實力的地方。
  • 你的專案網站——每個專案一個，即各公開儲存庫的 GitHub Pages 網站：專案 1 與它的報告、你的手機 App，以及專案 3——你的儀器（板上區塊、韌體、外殼）放在同一個儲存庫的同一個網站上——還有（如果你願意）一支介紹你的 App 與電路板的影片。
