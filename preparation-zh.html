第 1 講（AI）之前——workbook 第 0 章

第一堂課從最初幾分鐘就開始動手實作：14:25 每個人輸入 /tutor L1，14:42 每個人寫一份規格並和 Claude 一起做出一個倒立擺模擬器，15:10 每個人把它部署到公開網路，15:35 每個人把自己的韌體燒錄到 ESP32——所以這些工具與帳號必須事先在你的筆電上正常運作。 這份清單最多花一小時，不計入十小時的作業時數。以下每個步驟都附有一個 ✔ 檢查，讓你確認該步驟是否成功。如果哪裡出了問題，不要花超過 15 分鐘去解決—— 記下錯誤訊息，在課程 LINE 群組發問，並且第一堂課提早 20 分鐘到場。

小提示：一旦裝好 VS Code 與 Claude Code（步驟 2–3），你就可以請 Claude 幫你完成其餘步驟。 這不是作弊——這正是本課程的重點。例如你可以這樣問它：「幫我在 Windows 上安裝 uv 和 Python，並確認它們能正常運作。」

  1. 一台可以自行安裝軟體的筆電

    Windows 10/11、macOS 或 Linux。你需要管理員權限與大約 10 GB 的可用磁碟空間，以及一個 USB-A 埠（或 USB-C 轉接頭）以連接開發板——開發板會在第一天於教室門口發給你。

  2. 安裝 Visual Studio Code

    從 code.visualstudio.com/download 下載，並以預設選項安裝 （在 Windows 上，出現選項時請勾選「Add to PATH」與「Open with Code」）。

    ✔ 檢查：VS Code 能開啟。選單 Help → About 顯示版本編號。

  3. 安裝 Claude Code 擴充功能並登入課程組織

    在 VS Code 中按 Ctrl+Shift+X（macOS 為 Cmd+Shift+X），搜尋 Claude Code（發行者：Anthropic）並點選 Install—— 或從 marketplace 頁面安裝。 文件：Claude Code in VS Code。

    開課前你會收到本課程 Claude 組織的電子郵件邀請；請接受邀請，並在擴充功能要求登入時使用該帳號登入。 （若邀請尚未寄達，你仍可先安裝擴充功能，之後再登入。）上課時 Claude Code 就是你的家教（tutor）： /tutor L1 會用英文或中文帶你走過 workbook 的章節。

    ✔ 檢查：VS Code 側邊欄出現 Claude 圖示；登入後輸入「hello」可以得到回應。

  4. 安裝 git

    Windows：Git for Windows（預設選項即可）。macOS：開啟「終端機」輸入 git --version，出現安裝開發者工具的提示時請接受。 Linux：sudo apt install git（或你的發行版對應的指令）。

    接著告訴 git 你是誰（請使用與你 GitHub 帳號相同的電子郵件，見步驟 6）。在終端機中：

    git config --global user.name "Your Name"
git config --global user.email "you@example.com"

    ✔ 檢查：git --version 會印出版本編號。

  5. 透過 uv 安裝 Python

    我們使用 uv——一個快速的 Python 安裝與套件管理工具——而非 python.org 的安裝程式或 Anaconda。 課程後段，儀器的 Python 端（instrument.py）會在它上面執行。請依照安裝頁面操作；簡而言之：

    # Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

    關閉並重新開啟終端機，然後安裝 Python：uv python install 3.13

    ✔ 檢查：uv run python -c "print(2**10)" 會印出 1024。

    也請在 VS Code 中安裝 Python 擴充功能（搜尋「Python」，發行者為 Microsoft）。

  6. 建立個人 GitHub 帳號

    到 github.com/signup 註冊。請選一個專業的使用者名稱——它會出現在你公開作品的網址中，一用就是很多年。 系統詢問時請開啟雙重驗證（two-factor authentication）。身為學生，你也可以申請免費的 GitHub Student Developer Pack。

    將筆電上的 git 連上 GitHub：最簡單的方式是安裝 GitHub CLI 並執行 gh auth login （選擇 GitHub.com → HTTPS → 以網頁瀏覽器登入）。或者安裝 GitHub Desktop 並登入。

    ✔ 檢查：gh auth status 顯示你已登入。

  7. 加入課程的 GitHub 組織

    將你的 GitHub 使用者名稱寄給授課教師（電子郵件，或第一堂課提供的表單）。你會收到課程組織的邀請—— 請從郵件中或到 github.com/settings/organizations 接受邀請。

    該組織是 TIGP-Experimental-Methods（github.com/TIGP-Experimental-Methods）。它獨立於任何研究團隊之外，用途是逐年收藏本課程的專題成果。

    ✔ 檢查：該組織出現在你 GitHub 帳號的組織清單中。

  8. 安裝 PlatformIO 擴充功能

    我們用 PlatformIO 從 VS Code 為開發板寫入程式。在 VS Code 中按 Ctrl+Shift+X，搜尋 PlatformIO IDE 並安裝 （或依照 platformio.org 的說明）。第一次啟動時它會下載自己的工具鏈——請等它完成，並在提示時重新啟動 VS Code。 使用某些開發板時，Windows 使用者可能還需要 CP210x 或 FTDI USB 轉序列埠驅動程式。

    ✔ 檢查：側邊欄出現 PlatformIO（外星人頭）圖示；在它的 PlatformIO Core CLI 終端機中，pio --version 會印出版本編號。這是第一天家教最先檢查的東西。

  9. Clone 班級儲存庫

    整門課的工作都放在同一個儲存庫 TIGP-Experimental-Methods/class-board-2026： firmware/、host/（手機 App＋instrument.py）、hardware/（KiCad）、workbook/、tutor/，以及你自己的資料夾 docs/students/<name>/。 你在分支上工作並開 pull request；main 受保護，由授課教師合併。若還看不到這個儲存庫，請先接受步驟 7 的邀請。

    把它 clone 到你的筆電：在 VS Code 中，File → New Window，然後 Clone Git Repository…，貼上 https://github.com/TIGP-Experimental-Methods/class-board-2026，選擇一個資料夾，例如 Documents/tigp。

    ✔ 檢查：儲存庫資料夾已在 VS Code 中開啟，且在其終端機中 git status 顯示 On branch main。

  10. 建立免費的 Cloudflare 帳號並連上 GitHub

    第一天你會用 Cloudflare Pages 把你的第一個程式直接從 GitHub 儲存庫部署到公開網路，不需要建置步驟。 到 dash.cloudflare.com/sign-up 註冊（免費方案；驗證電子郵件）。然後連上 GitHub 一次：在儀表板進入 Workers & Pages → Create → Pages → Connect to Git，授權 Cloudflare 存取你的 GitHub 帳號，到這裡就停——專案本身在課堂上建立。

    ✔ 檢查：已登入 Cloudflare 儀表板；「Connect to Git」畫面列出你的 GitHub 帳號。（若 Cloudflare 註冊失敗，課堂上的備案是 GitHub Pages——不需要再裝任何東西。）

  11. 觀看 V1 與 V2（13 分鐘）

    V1 環境設定：VS Code、Claude Code、PlatformIO、git、clone 儲存庫（8 分鐘）帶你走過上面的步驟 2–9；V2 燒錄骨架韌體並在手機上開啟 App（5 分鐘）示範第一天 15:35 你要做的事。選看：V0 做出來、上線、記下來：網頁上的倒立擺（6 分鐘）預覽第一個練習。請依 workbook 第 0 章 進行——同一份清單，附完整指令；workbook 目錄列出後續章節。影片錄影將放在此處。

  12. 在 LINE 群組報到

    在課程 LINE 群組貼一張在 VS Code 中開著已 clone 儲存庫的截圖。這讓授課教師知道你的筆電已就緒；課程期間 LINE 群組也是你求助的地方（卡住超過 15 分鐘時，家教會請你到那裡發問）。

    ✔ 檢查：你的截圖已在群組裡。

  13. 知道你要做什麼

    每個人做的都是同一台班級儀器：一塊班級板、五個區塊（block）——B1 輸入 · B2 電源 · B3 輸出 · B4 切換 · B5 數位／TRIG——每位學生一個區塊。 你的區塊會在第 1 講結束時分配（先自願，再抽籤），所以事前沒有什麼需要選擇。不過，請帶著來自你自己實驗室的想法：有了這樣一個盒子，你會想監測、 觸發、切換或自動化什麼？可到點子庫找靈感。

第一週需要、第一天不需要（作業 1，練習 E4）

  1. 安裝 KiCad 10

    從 kicad.org/download 下載目前的穩定版（第 10 版），連同預設程式庫一併安裝。 安裝後先啟動一次，讓它完成符號庫與封裝庫的設定。作業 1 中你會把課程零件庫套件解壓到儲存庫、開啟 class-board.kicad_pro 並找到你的規則區域——影片 V4 有示範。

    ✔ 檢查：KiCad 能開啟；File → New Project 可用，且能開啟 Schematic Editor（電路圖編輯器）。

  2. 建立 JLCPCB 與 LCSC 帳號

    JLCPCB 負責製造與組裝班級板；LCSC 是與它配套的零件目錄，設計時我們使用其料號。 請建立免費帳號（兩者可用同一組登入）。現在不需要付款。

第 3 講（韌體與機械）之前

  1. 建立 Onshape 帳號

    外殼加碼使用 Onshape（免費教育方案，在瀏覽器中執行，無需安裝，任何筆電都能用）。 請以你的大學電子郵件註冊 Education 方案。第 3 講時，你會把授課教師的外殼範本——裡面已有電路板的 STEP 檔與前面板開孔——複製到自己的帳號、改一個地方、匯出 STL；由授課教師列印。

    ✔ 檢查：你能建立新文件並畫出一個矩形草圖。

  2. 可選：安裝切片軟體

    本課程的 3D 印表機是 Bambu，而且所有外殼都由授課教師列印，所以切片軟體不是必需的。若你想預覽自己的 STL 會怎麼列印，可安裝 Bambu Studio。
