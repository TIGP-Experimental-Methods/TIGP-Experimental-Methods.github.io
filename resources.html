Words we use

The tooling terms that recur on the course pages, one line each. Every page also explains a term the first time it appears there.

TermWhat it means
gitthe tool that records the history of a folder of files
GitHubthe website where repositories are stored and shared
repositorya project folder whose complete history git keeps; on GitHub it also lives online
clonedownload a full copy of a repository to your laptop
commitsave a snapshot of your changes with a one-line message
diffthe list of exactly what changed between two snapshots — what you review, rather than the whole file
pushupload your commits to GitHub
brancha separate line of work inside a repository, so several people can change things without treading on each other
mainthe main branch, the version everyone builds on — main always runs
mergebring a branch's changes into the main line
pull request (PR)a request to merge your branch into the shared project; someone reviews it first, comments, and approves
ring reviewerthe classmate who reviews your pull request (A reviews B, B reviews C, …, E reviews A)
CIcontinuous integration: an automatic build that GitHub runs on every pull request and reports green or red
GitHub CLI (gh)GitHub's command-line tool: log in, create repositories, open pull requests from the terminal (the text window where you type commands)
Markdownplain text with light formatting (# headings, - lists); what README, plan and handover files are written in
CLAUDE.md · PLAN.md · HANDOVER.mdplain-text files in the repository: how the project is set up (read by the agent every session) · what to build and in what order · what was done, verified, next, gotchas — so a fresh session can continue
coding agentClaude Code working on your files: it reads them, writes code, runs commands and reports back
context windoweverything the model sees in one session — the conversation, files and instructions; every message resends all of it, so keep it small: one topic per session
token · API keythe unit of text a model reads and writes (and is billed in) · the password that lets your program call a model or a service; keys are money and never go in a repository
Cloudflare Pages · GitHub Pagesfree services that turn a repository into a public web page (Cloudflare Workers add a backend)
deploypublish the page so it is live on the web
project website · project wallthe public GitHub Pages site of one project's repository (what it is, how it works, a picture or video of it working, what was verified, links to the app and the code) · the class page that shows every project as a card and refreshes itself every minute
webhooka web address a service (Telegram, LINE) calls when something happens — how a bot receives a message
microcontroller · dev boarda small computer on a chip; the development board carries it with a USB-C connector and pins. Ours is the ESP32-S3, which has WiFi
firmwarethe program that runs on the microcontroller
flashwrite the firmware onto the board over USB
PlatformIO · toolchainthe tool that builds and flashes the firmware for us · the compiler and helper programs it uses
SIM modea build in which the firmware fakes its hardware, so the app works on the bare dev board before the class board exists
access pointthe board's own WiFi network, which your phone joins
PWA · WebSocketthe phone app: a web page served by the board that behaves like an app · the live two-way connection between that page and the board
KiCadthe free program we draw the schematic and lay out the printed circuit board in
schematic · PCBthe circuit drawing · the physical board design with copper tracks
symbol · footprinta part's drawing in the schematic · the copper pattern it is soldered onto
ERC · DRCKiCad's electrical and design rule checks; zero errors means the checks pass
rule area (zone) · routingthe outlined region of the board that is yours · drawing the copper tracks between parts
JLCPCBthe factory that makes and assembles our boards; parts come from its parts library (part numbers like C12345 — no LCSC account needed)
BOM · Gerbersthe parts list · the manufacturing files sent to the factory
STL · STEP · DXF3D file formats: for printing · for CAD exchange · and the 2D drawing format for laser cutting
Onshapethe browser CAD program we suggest for the housing (any CAD program is fine)
GPIO · SPI · I²Ca general-purpose pin on the microcontroller · two common wiring standards for chips to talk to it

Agents and documentation

  • Claude Code documentation — getting started, CLAUDE.md, skills, hooks, subagents, MCP; the VS Code extension (our choice: low lock-in, your code and history stay yours).
  • Claude Code best practices (Anthropic engineering blog).
  • Other ways to run an agent: Claude Cowork · Claude Design. The independent reviewer of a plan or of code is a fresh Claude session that has not seen the work.
  • Anthropic Console — API keys for putting an LLM inside your own app; API documentation. Keys are money: keep them out of the repository.
  • Markdown guide (plain text with light formatting) · Writing on GitHub

Git and GitHub

  • Source Control in VS Code — edit → stage → commit without a terminal · GitHub Hello World · Pro Git (free book)

Deployment, for free

  • GitHub Pages (static pages from a public repository — every project website, and any app that runs entirely in the browser, at https://<user>.github.io/<repo>/)
  • Cloudflare Pages + Cloudflare Workers (straight from a GitHub repository; free tier — for anything with a backend, a bot webhook or a secret). You may need both hosts, so have both accounts ready.
  • YouTube (unlisted) — video that only people with the link can see
  • Hugging Face Spaces (demos of apps and models) · Zenodo (data and code with a citable DOI)
