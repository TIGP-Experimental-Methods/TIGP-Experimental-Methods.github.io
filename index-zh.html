一個月打造一台真正的實驗室儀器

這是一門為實驗物理研究生開設的實作短期課程。在三場各兩小時的工作坊中，你將學到完成一件小巧、真正實用的實驗室裝置所需的三套技能：由 AI 程式代理（coding agent）協助撰寫的韌體與軟體、裝在專業組裝 PCB 上的電子電路，以及從參數式 CAD 範本設計、再 3D 列印的外殼。

在工作坊進行的同時——連續三週每週約三小時，作業總共十小時，這是我們的承諾——你將製作班級儀器中屬於你的那一部分：一塊板、五個區塊（block）、五位學生、一個儲存庫。這塊板插在 ESP32-S3 開發板上，補上開發板做不到的事：2 路 ±10 V 16 位元波形輸出、8 路 ±10 V 16 位元輸入、4 個繼電器、2 路隔離快速輸入、8 路 TTL 輸出與 2 路快速觸發輸出、可切換方向的 TRIG、手機 App、Python API 與 OLED——全部只靠一條 USB-C 線。你負責 PCB 上你的區塊的區域佈線、審查一位同學的成果、撰寫你區塊的驅動程式與 App 面板，並為外殼加上個人風格。在展示週（暫定：10月26–30日），你將依班級檢查清單進行一場 5 分鐘的現場展示——輸出波形，在示波器與儀器自己的輸入上都看得到 · 從手機改變它 · 警報 → 繼電器 → 通知 · 你的區塊——並以你的 60 秒影片作為安全網。

本課程要傳達的訊息是：AI 能讓物理學家發揮出大約相當於一位稱職的電機、機械與軟體工程師 80% 的實力——但前提是你必須能明確說出你要什麼，並驗證你得到了什麼。「規格制定」與「驗證」才是我們真正要教的技能。

第一堂課之前，請先完成課前準備檢查清單（workbook 第 0 章，最多一小時——不計入那十小時）。請自備筆記型電腦；開發板會在教室門口發給你。

課程如何進行

一個專題，三種視角

三堂課並不是各自獨立的主題——它們是完成同一件裝置所需的三種技能：班級儀器。每一項練習都在同一塊班級板上你自己的區塊做一次，而你區塊的面板與你的外殼讓它成為你獨有的作品。

工作坊，而非講座

每堂課以「示範 → 實作 → 檢討」的短區塊反覆進行，並由 Claude 家教（Claude Code 中的 /tutor）用英文或中文帶你走過每一個實作步驟與作業。理論只在能幫你做出決定時才出現（例如「±10 V 與 16 位元買到了什麼？」）。

AI 撰寫，你來驗證

我們在班級儲存庫中以代理模式使用 VS Code + Claude Code。你將學會讓 AI 輔助工程可靠運作的工作方法——先寫規格、專案慣例檔、開新的工作階段、交接筆記、平行代理。

每一步都真的做一次

出貨硬體的每一步都真的做一次——放回缺少的零件、從 LCSC 下載一個零件、為你的區域佈線、開 PR、審查同學——然後你的區域進入一塊專業組裝的板子，裝在外殼裡由你展示。作業最多十小時：少而精。
