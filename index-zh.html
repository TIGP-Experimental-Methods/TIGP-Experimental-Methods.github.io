一個月打造一台真正的實驗室儀器

這是一門為實驗物理研究生開設的實作短期課程：三場工作坊，然後是你專案的成果發表與展示。

  • 工作坊 1：實驗物理學家的 AI——大型語言模型如何運作、我們使用的工具（VS Code、Claude Code 擴充功能（extension）、git、免費網頁託管）、我們的「AI 方法」五步驟，以及兩個專案：專案 1，一個你自選的網頁應用程式（模擬器或遊戲），部署（deploy）到公開網路；專案 2，一個透過 WiFi 控制 ESP32（一塊小型 WiFi 微控制器（microcontroller）板，課堂提供）並從它讀取量測值的手機 App。
  • 工作坊 2：設計印刷電路板——電子學速成班，然後是專案 3a：把我們的 ESP32 變成真正的實驗室設備。我們一起在 KiCad（我們用來畫電路與佈局電路板的免費軟體）中建好班級板的骨架；每個人設計一個不同的區塊（section），所以全班合力做出一台強大的儀器。板子由 JLCPCB 製造並組裝。
  • 工作坊 3：韌體與基礎機械設計（PCB 外殼）——參觀原分所的製造設施、CAD 基礎，以及專案 3b：為你的儀器做一個外殼（housing；3D 列印和／或雷射切割），同時你繼續開發你的 App 與韌體（firmware）。
  • 成果發表與展示（10月26–30日）——領取組裝完成的板子與外殼，組裝、測試，然後發表並展示你的專案、App、網站，以及（如果你願意）一段影片。

班級板插在 ESP32-S3 開發板（dev board：一顆帶 WiFi 的單晶片小電腦，裝在有 USB-C 接頭與腳位的板子上）上，補上開發板做不到的事：2 路 ±10 V 16 位元波形輸出、8 路 ±10 V 16 位元輸入、4 個繼電器、2 路隔離快速輸入、8 路 TTL 輸出（5 V 邏輯準位訊號）與 2 路快速觸發輸出、可切換的 TRIG、 手機 App、Python API（從電腦驅動這塊板子的一組 Python 指令）與 OLED（小型顯示器）——全部只靠一條 USB-C 線。你能把它改造成解決你目前研究中某個問題的工具嗎？

本課程要傳達的訊息是：有效運用 AI 是實驗物理學家的超能力——只要你能明確說出你要什麼，並驗證你得到了什麼。沒有測試與驗證，絕不信任 AI。

第一堂課之前，請先完成課前準備的各個步驟。請自備已完整準備好的筆記型電腦；ESP32 板由課堂提供。

課程目標

教授每一個現代實驗物理實驗室都需要的關鍵技能。

智慧

軟體與 AI：一個能規劃、撰寫、測試並部署你所指定程式的 AI 程式代理（agent）——以及如何可靠地與它合作。

電子

電子學是我們把智慧接上真實世界的方式：一塊印刷電路板（PCB），為微控制器提供精確的輸入、輸出與切換。

機械

做出實體硬體——CAD、3D 列印與雷射切割——讓板子成為一台可以放在工作檯上的儀器。

我們不教 AI 的運作原理，也不教電子或機械工程（那要花好幾年）。我們的目標是給你一堂速成課，學會啟動自己專案所需的工具。

課程如何進行

一個專案，三場工作坊

三場工作坊並不是各自獨立的主題——它們是打造同一件裝置所需的三種技能：班級儀器。你的網頁應用程式、你的手機 App、你在板子上的區塊與你的外殼，最後都匯入你的專案。

工作坊，而非講座

每場工作坊是一段簡短的介紹，接著就是動手做，並有 Claude 家教（tutor；Claude Code 中的 /tutor）在旁協助，英文或中文皆可。理論只在能幫你做出決定時才出現——請家教解釋一個概念，也讓它反過來問你問題。

「AI 方法」五步驟

願景（Vision）→ 規格／計畫（Specification/Plan）→ 審查（Review）→ 寫程式（Code）→ 測試／除錯／驗證（Test/Debug/Verify），然後反覆迭代：第一版計畫永遠不是最後一版。我們使用 VS Code + Claude Code 擴充功能，以 git 作為安全網。沒有測試與驗證，絕不信任 AI。

每一步都真的做一次

部署一個真正的 App、設計一塊真正板子上真正的區塊、畫一個真正的外殼——然後你的區塊進入一塊專業組裝的板子，裝在外殼裡由你展示。發揮創意。

課程結束時你會做出的東西

  • 一個已部署的網頁應用程式——模擬器或遊戲——附上說明其概念的報告。
  • 一個透過 WiFi 控制你 ESP32 的手機 App。
  • 你在班級板上的區塊，以 KiCad 設計並製造完成。
  • 一個儀器的外殼，3D 列印和／或雷射切割。
  • 你專案及其網站的成果發表與展示——以及，可選的，一段介紹你的 App 與板子的影片。

每個專案都放在你帳號下自己的公開 GitHub 儲存庫（repository）裡，並有自己的專案網站（GitHub Pages：它是什麼、如何運作、一張它運作中的照片或影片、驗證了什麼、連到 App 與程式碼的連結）。所有專案都會出現在班級專案牆上——上課時投影在螢幕上，每分鐘自動更新，所以大家都看得到彼此的專案陸續出現。見成果展。

硬體是全班共同的基準線。軟體、韌體與 App 是開放的——資料記錄器、LINE 通知、PID 區塊、Python 掃描、你實驗室需要的工具。那裡才是你展現能力的地方。用 LINE 或 Telegram 和你的儀器對話——我們最鼓勵的延伸：數值飄移或警報觸發時推播通知，以及能從手機讀取數值、切換繼電器的機器人指令，隨時隨地。盡管做出很棒的東西。
