我們用的詞

課程網頁反覆出現的工具名詞，每個一行。每一頁在名詞第一次出現時也會就地解釋。

名詞意思
git記錄一個資料夾中檔案歷史的工具
GitHub存放並分享儲存庫的網站
repository 儲存庫由 git 保存完整歷史的專案資料夾；放在 GitHub 上就同時有一份線上版
clone 複製把儲存庫的完整副本下載到你的筆電
commit 提交把你的修改存成一個快照，附一行說明
diff 差異兩個快照之間究竟改了什麼的清單——你審查的是它，而不是整個檔案
push 推送把你的提交上傳到 GitHub
branch 分支儲存庫內各自獨立的一條工作線，讓多人修改時不互相踩到
main主分支，大家共同依據的版本——main 永遠要能跑
merge 合併把一個分支的修改併入主線
pull request（PR）拉取請求請求把你的分支併入共用專案；先由某人審查、留意見並核准
ring reviewer 環狀審查者審查你拉取請求的同學（A 審 B、B 審 C、……、E 審 A）
CI 持續整合continuous integration：GitHub 對每個拉取請求自動執行的建置，並回報綠燈或紅燈
GitHub CLI（gh）GitHub 的命令列工具：在終端機（輸入指令的文字視窗）登入、建立儲存庫、開拉取請求
Markdown帶輕量格式的純文字（# 標題、- 清單）；README、計畫與交接檔案都用它寫
CLAUDE.md · PLAN.md · HANDOVER.md儲存庫裡的純文字檔：專案如何設定（代理每個工作階段都會讀）· 要做什麼、依什麼順序 · 已完成、已驗證、下一步、注意事項——讓新的工作階段能接著做
coding agent 程式代理在你的檔案上工作的 Claude Code：讀檔、寫程式、執行指令並回報
context window 情境視窗模型在一個工作階段（session）中看到的一切——對話、檔案與指示；每則訊息都會把它全部重送一次，所以要保持精簡：一個工作階段只談一個主題
token 權杖 · API key 金鑰模型讀寫（也是計費）的文字單位 · 讓你的程式能呼叫模型或服務的密碼；金鑰就是錢，絕不放進儲存庫
Cloudflare Pages · GitHub Pages把儲存庫變成公開網頁的免費服務（Cloudflare Workers 再加上後端）
deploy 部署把網頁發布上線
project website 專案網站 · project wall 專案牆一個專案儲存庫的公開 GitHub Pages 網站（它是什麼、如何運作、一張它運作中的照片或影片、驗證了什麼、連到 App 與程式碼的連結）· 把全班每個專案以卡片呈現、每分鐘自動更新的班級頁面
webhook 網頁掛鉤一個網址，某項服務（Telegram、LINE）在事情發生時會來呼叫——機器人就是這樣收到訊息的
microcontroller 微控制器 · dev board 開發板單晶片上的小電腦；開發板載著它，附 USB-C 接頭與腳位。我們用的是帶 WiFi 的 ESP32-S3
firmware 韌體在微控制器上執行的程式
flash 燒錄經 USB 把韌體寫進板子
PlatformIO · toolchain 工具鏈為我們建置並燒錄韌體的工具 · 它使用的編譯器與輔助程式
SIM mode 模擬模式讓韌體假造自己硬體的一種建置，班級板還沒到手前 App 就能在光板開發板上跑
access point 存取點板子自己發出的 WiFi 網路，用手機加入
PWA · WebSocket手機 App：由板子提供、像 App 一樣運作的網頁 · 該網頁與板子之間的即時雙向連線
KiCad我們用來畫電路圖與佈局印刷電路板的免費軟體
schematic 電路圖 · PCB 印刷電路板電路的圖 · 帶銅箔走線的實體電路板設計
symbol 符號 · footprint 封裝零件在電路圖中的圖形 · 零件焊上去的銅箔圖形
ERC · DRCKiCad 的電氣規則檢查與設計規則檢查；零錯誤即通過
rule area（zone）規則區域 · routing 佈線板上劃給你的框出區域 · 畫出零件之間的銅箔走線
JLCPCB製造並組裝班級板的工廠；零件來自它的零件庫（料號形如 C12345——不需要 LCSC 帳號）
BOM 物料清單 · Gerber零件清單 · 送去工廠的製造檔
STL · STEP · DXF3D 檔案格式：列印用 · CAD 交換用 · 以及雷射切割用的 2D 圖檔格式
Onshape我們建議用來做外殼（housing）的瀏覽器 CAD 軟體（任何 CAD 軟體都可以）
GPIO · SPI · I²C微控制器上的通用腳位 · 晶片與微控制器對話的兩種常見接線標準

實驗物理學家的 AI——工作坊 1 提到的工具

代理與文件

  • Claude Code 文件——入門、CLAUDE.md、技能（skill）、鉤子（hook）、子代理（subagent）、MCP；VS Code 擴充功能（我們的選擇：綁定程度低，你的程式碼與歷史都還是你的）。
  • Claude Code 最佳實務（Anthropic 工程部落格）。
  • 執行代理（agent）的其他方式：Claude Cowork · Claude Design。計畫或程式碼的獨立審查者，是一個沒看過這份工作的全新 Claude 工作階段。
  • Anthropic Console——把 LLM 放進自己 App 所需的 API 金鑰；API 文件。金鑰就是錢：別放進儲存庫。
  • Markdown 指南（帶輕量格式的純文字）· 在 GitHub 上寫作

Git 與 GitHub

  • VS Code 的原始碼控制——不用終端機也能編輯 → 暫存 → 提交 · GitHub Hello World · Pro Git（免費書籍）

免費部署

  • GitHub Pages（從公開儲存庫產生靜態網頁——每個專案網站，以及任何完全在瀏覽器裡執行的 App，網址 https://<user>.github.io/<repo>/）
  • Cloudflare Pages＋Cloudflare Workers（直接從 GitHub 儲存庫部署；有免費方案——任何有後端、機器人網頁掛鉤（webhook）或機密的東西都放這裡）。你可能兩個主機都需要，所以兩個帳號都要準備好。
  • YouTube（不公開）——只有拿到連結的人才看得到的影片
  • Hugging Face Spaces（App 與模型的展示）· Zenodo（附可引用 DOI 的資料與程式碼）

會跟你說話的 App

  • Telegram Bot API——用 @BotFather 建立機器人；最容易的起點
  • LINE Messaging API——台灣人人都有的 App；先從 Telegram 開始，再移植到 LINE
  • ntfy.sh——只做推播通知，不需要機器人

語音、影片與圖像

  • OpenAI Whisper（語音轉文字）· Chatterbox（文字轉語音，開放原始碼）
  • show-your-work——實驗室公開的影片、投影片與報告製作流程：五個 Claude Code 技能（education-video、slide-deck、technical-report、natural-voice、showoff-render）；先寫腳本，最後才做圖。選用，適合專案 1 的簡報延伸，以及介紹你的儀器的影片。
  • Blender（從 CAD 模型以程式產生硬體的渲染圖）· Unreal Engine（場景）。生成的圖像要標示清楚。
  • 用 Markdown 做投影片：Marp · reveal.js。繪製圖表：Mermaid、draw.io。螢幕錄影：OBS Studio。

Python 與儀器

  • uv 指南 · Python 教學 · matplotlib 圖庫 · pySerial · PyVISA（儀器控制）
  • 在瀏覽器裡做專案 1：MDN canvas 教學（模擬器或遊戲網頁通常就是用它畫的）。
  • 原分所：SAIL Club（Sharing AI Lunch Club）與其資源頁面。
