Before lecture 1 (AI) — workbook chapter 0

The first class is hands-on from the first minutes: at 14:25 everyone types /tutor L1, at 14:42 everyone writes a spec and builds a pendulum simulator with Claude, at 15:10 everyone deploys it to the public web, and at 15:35 everyone flashes their own firmware to their ESP32 — so the tools and accounts must already work on your laptop. This checklist takes at most an hour and is not counted in the ten hours of homework. Every step below has a ✔ check that tells you it worked. If anything fails, don't spend more than 15 minutes on it — note the error message, ask in the course LINE group, and come 20 minutes early to the first class.

Tip: once you have VS Code and Claude Code installed (steps 2–3) you can ask Claude to help you with the remaining steps. That is not cheating — it is the point of the course. Ask it, for example: "Help me install uv and Python on Windows and check that it works."

  1. A laptop you can install software on

    Windows 10/11, macOS or Linux. You need administrator rights and about 10 GB of free disk space. A USB-A port (or a USB-C adapter) for the dev board, which you receive at the door on day 1.

  2. Install Visual Studio Code

    Download from code.visualstudio.com/download and install with default options (on Windows, tick "Add to PATH" and "Open with Code" when offered).

    ✔ check: VS Code opens. In the menu Help → About shows a version number.

  3. Install the Claude Code extension and sign in to the course organization

    In VS Code press Ctrl+Shift+X (macOS Cmd+Shift+X), search for Claude Code (publisher: Anthropic) and click Install — or install from the marketplace page. Documentation: Claude Code in VS Code.

    You will receive an invitation to the course's Claude organization by email before the first class; accept it and sign in with that account when the extension asks. (If the invitation has not arrived, you can still install the extension now and sign in later.) In class, Claude Code is your tutor: /tutor L1 paces you through the workbook chapter, in English or Mandarin.

    ✔ check: A Claude icon appears in the VS Code side bar; after signing in you can type "hello" and get an answer.

  4. Install git

    Windows: Git for Windows (defaults are fine). macOS: open Terminal and type git --version; accept the prompt to install the developer tools. Linux: sudo apt install git (or your distribution's equivalent).

    Then tell git who you are (use the same email as your GitHub account, step 6). In a terminal:

    git config --global user.name "Your Name"
git config --global user.email "you@example.com"

    ✔ check: git --version prints a version.

  5. Install Python via uv

    We use uv, a fast Python installer and package manager, rather than python.org installers or Anaconda. The Python side of the instrument (instrument.py) runs on it later in the course. Follow the installation page; in short:

    # Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

    Close and reopen the terminal, then install Python: uv python install 3.13

    ✔ check: uv run python -c "print(2**10)" prints 1024.

    Also install the Python extension in VS Code (search "Python", publisher Microsoft).

  6. Create a personal GitHub account

    Sign up at github.com/signup. Choose a professional username — it will be in the URL of your public work for years. Turn on two-factor authentication when asked. As a student you can also apply for the free GitHub Student Developer Pack.

    Connect git on your laptop to GitHub: the simplest way is to install the GitHub CLI and run gh auth login (choose GitHub.com → HTTPS → login with a web browser). Alternatively install GitHub Desktop and sign in.

    ✔ check: gh auth status says you are logged in.

  7. Join the class GitHub organization

    Send your GitHub username to the instructor (email or the form given in the first class). You will receive an invitation to the class organization — accept it from the email or at github.com/settings/organizations.

    The organization is TIGP-Experimental-Methods (github.com/TIGP-Experimental-Methods). It is separate from any research group and exists to collect the class projects year after year.

    ✔ check: The organization appears in your list of organizations on GitHub.

  8. Install the PlatformIO extension

    We program the dev board from VS Code with PlatformIO. In VS Code press Ctrl+Shift+X, search for PlatformIO IDE and install it (or follow platformio.org). On first start it downloads its own toolchain — let it finish and restart VS Code when asked. Windows users may also need the CP210x or FTDI USB-serial drivers for some boards.

    ✔ check: The PlatformIO (alien head) icon appears in the side bar; in its PlatformIO Core CLI terminal, pio --version prints a version. This is the first thing the tutor checks on day 1.

  9. Clone the class repository

    All course work lives in one repository, TIGP-Experimental-Methods/class-board-2026: firmware/, host/ (phone app + instrument.py), hardware/ (KiCad), workbook/, tutor/, and your own folder docs/students/<name>/. You work on branches and open pull requests; main is protected and the instructor merges. If the repository is not visible yet, accept the invitation from step 7 first.

    Clone it to your laptop: in VS Code, File → New Window, then Clone Git Repository…, paste https://github.com/TIGP-Experimental-Methods/class-board-2026, choose a folder such as Documents/tigp.

    ✔ check: The repo folder is open in VS Code and git status in its terminal says On branch main.

  10. Create a free Cloudflare account and connect it to GitHub

    On day 1 you deploy your first program to the public web with Cloudflare Pages, straight from a GitHub repository, no build step. Sign up at dash.cloudflare.com/sign-up (free plan; verify the email). Then, once, connect GitHub: in the dashboard go to Workers & Pages → Create → Pages → Connect to Git, authorise Cloudflare for your GitHub account, and stop there — you create the project itself in class.

    ✔ check: Signed in to the Cloudflare dashboard; the "Connect to Git" screen lists your GitHub account. (If Cloudflare sign-up fails, GitHub Pages is the fallback in class — nothing else to install.)

  11. Watch V1 and V2 (13 minutes)

    V1 Setup: VS Code, Claude Code, PlatformIO, git, clone the repo (8 min) walks through steps 2–9 above; V2 Flash the skeleton and open the app on your phone (5 min) shows exactly what you will do at 15:35 on day 1. Optional preview: V0 Build, ship, log: a pendulum on the web (6 min) shows the first exercise. Follow workbook chapter 0 — the same list with the exact commands; the workbook index shows what comes next. Video recordings follow here.

  12. Check in on the LINE group

    Post a screenshot of the cloned repository open in VS Code to the course LINE group. That tells the instructor your laptop is ready, and the LINE group is where you ask for help during the course (the tutor will send you there when you are stuck for more than 15 minutes).

    ✔ check: Your screenshot is in the group.

  13. Know what you are going to build

    Everyone builds the same class instrument: one class board with five blocks — B1 inputs · B2 power · B3 outputs · B4 switching · B5 digital/TRIG — and one block per student. Your block is assigned at the end of lecture 1 (volunteers first, then lots), so there is nothing to choose beforehand. Do come with an idea from your own lab, though: what would you monitor, trigger, switch or automate with a box like this? For inspiration, browse the idea archive.

Needed in week 1, not on day 1 (Homework 1, exercise E4)

  1. Install KiCad 10

    Download the current stable release (version 10) from kicad.org/download. Install with the default libraries. Start it once so it finishes configuring the symbol and footprint libraries. In Homework 1 you then unzip the course library package into the repo, open class-board.kicad_pro and find your rule area — video V4 shows it.

    ✔ check: KiCad opens; File → New Project works and you can open the Schematic Editor.

  2. Create accounts at JLCPCB and LCSC

    JLCPCB manufactures and assembles the class board; LCSC is the associated parts catalogue whose part numbers we use during design. Create free accounts (same login works for both). No payment needed now.

Before lecture 3 (Firmware and Mechanical)

  1. Create an Onshape account

    The box add-on uses Onshape (free education plan, runs in the browser, no installation, works on any laptop). Sign up with your university email under the Education plan. In lecture 3 you copy the instructor's box template — it already contains the board STEP and the front-panel cutouts — into your account, change one thing, and export an STL; the instructor prints it.

    ✔ check: You can create a new document and sketch a rectangle.

  2. Optional: install a slicer

    The course 3D printers are Bambu and the instructor prints all the boxes, so a slicer is not required. If you want to preview how your STL will print, install Bambu Studio.
